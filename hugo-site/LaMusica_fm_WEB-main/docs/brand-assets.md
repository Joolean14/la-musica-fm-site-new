# Activos y convivencia de marcas

## Regla general

LaMúsica.fm articula el sitio y conserva su navegación, retícula, jerarquía, accesibilidad y sistema de conexiones. Las demás identidades aparecen cuando el contenido habla de ellas o cuando una relación entre servicios y proyectos necesita mostrarse.

No redibujar, recolorear, deformar, recortar ni fusionar logos. No construir fondos, patrones o texturas repitiendo una marca.

## Aplicación por página

- Página o bloque de una sola marca: usar su logo y recursos dentro del tramo correspondiente, manteniendo la estructura de LaMúsica.fm.
- Página de conexiones: cada identidad conserva su propio módulo; las relaciones se muestran con líneas, proximidad, nodos o transiciones del sistema de LaMúsica.fm.
- Servicios compartidos: mostrar primero la necesidad y el servicio; las marcas participantes aparecen después como responsables, proyectos relacionados o rutas de salida.
- Fondo claro: usar la variante oscura o principal con contraste comprobado.
- Fondo oscuro: usar la variante blanca cuando esté disponible.
- Ausencia de variante adecuada: cambiar la superficie o la composición. No alterar el archivo.

## Responsive y accesibilidad

- Conservar proporción y espacio libre alrededor del logo.
- Definir dimensiones para evitar saltos de diseño.
- Usar texto alternativo con el nombre de la marca cuando el logo identifica una entidad enlazada; usar `alt=""` si repite un encabezado inmediato.
- En móvil, las marcas se ordenan como módulos verticales; las conexiones visuales tienen una lista textual equivalente.
