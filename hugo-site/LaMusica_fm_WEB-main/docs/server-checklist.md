# Lista de salida a servidor

## Antes de desplegar
- Confirmar dominio, hosting, acceso al servidor y mecanismo de despliegue.
- Registrar stack, versiones y comandos en el README del repositorio.
- Crear staging protegido y verificar que no sea indexable.
- Hacer copia recuperable de archivos y base de datos del sitio actual.
- Configurar variables de entorno del formulario, analítica y servicios externos.
- Cargar logo, imágenes, diploma CoCrea y archivos históricos en sus rutas definitivas.

## Pruebas
- Escritorio: últimas versiones de Chrome, Firefox, Edge y Safari.
- Móvil: Android Chrome e iOS Safari.
- Navegación por teclado, lector de pantalla básico y reducción de movimiento.
- Formulario: validación, anti-spam, éxito, error y recepción real.
- Todas las rutas, enlaces internos y externos.
- Estados 200, 301 y 404.
- Title, description, canonical, Open Graph, sitemap y robots.
- Imágenes, fuentes, caché, HTTPS y ausencia de contenido mixto.

## Después de desplegar
- Revisar errores de servidor y consola.
- Confirmar recepción del formulario.
- Enviar sitemap a la herramienta de búsqueda configurada.
- Revisar rutas principales y redirecciones desde una red externa.
- Conservar la copia anterior hasta cerrar la verificación.
