# Portada - referencia de implementación

Esta carpeta contiene la base visual aprobada para el inicio de LaMúsica.fm: navegación, primer tramo, mapa de conexiones, selector de seis necesidades, comportamiento responsivo, foco visible y reducción de movimiento.

## Uso
- Adaptar la estructura al stack existente del repositorio.
- Reemplazar el contenido mediante `content/site-content.json`.
- Usar `assets/brand/logo-lamusica.png`; no reconstruir el logo.
- Conservar colores, tipografías, contraste y función del hexágono.
- Completar el menú móvil con control de foco, Escape y `aria-expanded`.

Los archivos HTML y CSS sirven como referencia de composición y comportamiento. La integración final debe usar los componentes y convenciones del proyecto.
